Systems and embedded engineer at **Zeta Defence**. I spend most of my time a few layers below the framework — kernels, bare-metal MCUs, packet paths, and the parts of a program that only make sense in a debugger. Occasionally I surface into userland to make pixels move fast.

## Selected work

| Project | Built with | What it is |
|:--|:--|:--|
| [**photon**](https://github.com/coredumpdev/photon) | TypeScript · WebGL2 | GPU-accelerated scientific plotting for the web. Line, scatter, heatmap, contour, polar and 3D — millions of points at 60 fps. |
| [**disasm-ai**](https://github.com/coredumpdev/disasm-ai) | TypeScript · Electron | AI-assisted, multi-architecture reverse engineering, built on rizin and rz-ghidra. |
| [**in-mem-db**](https://github.com/coredumpdev/in-mem-db) | C | An in-memory database written from scratch. |
| [**basic-os**](https://github.com/coredumpdev/basic-os) | C++ · Assembly | An x86 kernel, from the bootloader up. |
| [**stm32-bare-matel-f429zi**](https://github.com/coredumpdev/stm32-bare-matel-f429zi) | Assembly | Bare-metal Cortex-M4 on the STM32F429ZI — no HAL, no RTOS. |
| [**pcap-capture**](https://github.com/coredumpdev/pcap-capture) | C++ | Packet capture and dissection. |
